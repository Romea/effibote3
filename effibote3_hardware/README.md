# effibote3_hardware

## 1) Overview

`effibote3_hardware` provides the live `ros2_control` hardware plugin for the Effibot E3 mobile base.

It specializes the generic `4WD` hardware abstraction from `romea_mobile_base_hardware` and connects it to the Effibot E3 low-level controller through a serial link.

The exported plugin is:

| Plugin | Base class | Mobile base architecture |
|---|---|---|
| `effibote3_hardware/EffibotE3Hardware` | `HardwareSystemInterface4WD` | `4WD` |

## 2) Hardware concept

`EffibotE3Hardware` is loaded by `controller_manager` from the `<ros2_control>` description generated by `effibote3_description`.

At runtime, it:

1. opens the Effibot E3 serial port;
2. reads the Effibot E3 `ros2_control` hardware information;
3. creates the `HardwareInterface4WD` command and state interface mapping;
4. loads wheel geometry used to convert wheel angular speeds;
5. sends an active-mode command when the hardware is activated;
6. starts a serial listening thread for Effibot E3 feedback frames;
7. converts controller wheel commands into Effibot E3 linear and angular speed commands;
8. sends heartbeat frames and speed commands to the robot;
9. converts received wheel speed feedback into `ros2_control` state interfaces;
10. sends a null command and inactive-mode command when the hardware is deactivated.

From the controller point of view, this behaves like a standard mobile base hardware plugin: `romea_mobile_base_controllers/MobileBaseController4WD` writes wheel speed commands and reads wheel speed feedback from state interfaces to compute odometry.

## 3) Serial communication

The current implementation uses the following serial device:

```text
/dev/serial/by-id/usb-Prolific_Technology_Inc._USB-Serial_Controller_D-if00-port0
```

with a baudrate of:

```text
115200
```

The hardware plugin sends:

* speed commands encoded as linear and angular speed;
* active-mode and inactive-mode commands;
* heartbeat frames;
* null commands when the interface is activated, deactivated or disconnected.

It receives:

* left wheel speed feedback;
* right wheel speed feedback;
* low-level replies and status frames.

The frame protocol uses a fixed-size message with header, sequence number, command id, payload and CRC.

## 4) Relation with other packages

`effibote3_hardware` is the live hardware specialization of the Effibot E3 mobile base:

* `effibote3_description` selects `effibote3_hardware/EffibotE3Hardware` in `live` mode;
* `romea_mobile_base_hardware` provides the reusable `4WD` hardware abstraction;
* `romea_mobile_base_utils` provides helpers used to read `hardware_interface::HardwareInfo`;
* `romea_mobile_base_controllers` sends commands through the exported `ros2_control` interfaces;
* `effibote3_bringup` starts the controller manager and loads this hardware plugin in live mode.
